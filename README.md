## 📂 Repository Architecture & Labs

This repository is organized into hands-on labs, automation tooling, and policy frameworks:

* **`AWS S3 Compliance-as-Code Auditor/`** — A compliance auditor lab mapping cloud security controls against NIST standards to automate configuration checks.
* **`Basic SQL Lab/`** — Practical database security labs and queries focusing on access control, filtering data, and understanding table relationships.
* **`automation_scripts/`** — Scripts built to handle recurring GRC and infrastructure tasks automatically.
* **`policies/`** — Scalable governance artifacts, including corporate access control, vendor risk assessments, Linux server audits, and AI governance rules.
