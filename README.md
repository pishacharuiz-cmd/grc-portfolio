# GRC & Compliance-as-Code Portfolio

Welcome to my governance, risk, and compliance (GRC) portfolio. This repository bridges the gap between traditional security policies and modern engineering by applying a **Compliance-as-Code** approach—moving away from static spreadsheets and manual paperwork toward continuous, automated assurance.

---

## 🎯 The Core Objective
Traditional GRC workflows rely heavily on manual periodic spreadsheet reviews. This project demonstrates an automated alternative: **building digital guards that programmatically pull configuration states, evaluate security controls in real time, and generate actionable remediation reports.**
