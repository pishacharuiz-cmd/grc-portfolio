# IT General Controls (ITGC) Audit Lab

## Overview

This project simulates an IT General Controls audit for a fictional organization.

The objective is to demonstrate the process of evaluating IT controls through:

- Control identification
- Evidence collection
- Control testing
- Exception identification
- Risk assessment
- Remediation recommendations
- Retesting

## Audit Scenario

**Organization:** CaribeTech Services  
**Industry:** SaaS / Business Services  
**Audit Period:** January–June 2026  
**Audit Type:** IT General Controls Review

## Audit Scope

The review covers four ITGC areas:

1. User Access Management
2. Privileged Access Management
3. Change Management
4. User Termination

## Methodology

Each control will be evaluated using the following process:

> Control → Evidence → Testing → Finding → Risk → Remediation → Retest

## Framework References

This lab uses concepts from:

- COBIT 2019
- NIST Cybersecurity Framework
- Common IT audit and SOC 1 control-testing practices

## Project Objective

The purpose of this lab is to demonstrate practical IT audit and GRC skills by testing simulated organizational evidence rather than simply documenting theoretical controls.
